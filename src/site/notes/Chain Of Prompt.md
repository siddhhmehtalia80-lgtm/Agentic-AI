**Prompt chaining** (or chain-of-prompts) is a technique in AI engineering where a complex task is broken down into a series of smaller, sequential steps. Instead of asking an AI model to complete a massive or multi-layered task in a single prompt, the output of one prompt is fed as the input into the next prompt.

## How Prompt Chaining Works

In a standard workflow, a user or system creates a pipeline where each step has a specialized role.

```
[ Step 1: Raw Input ] ──► ( Prompt 1: Extract Key Topics ) ──► [ Output A ]
                                                                     │
[ Step 2: Analysis ]  ──► ( Prompt 2: Analyze Output A )   ──► [ Output B ]
                                                                     │
[ Step 3: Synthesis ] ──► ( Prompt 3: Format Output B )    ──► [ Final Output ]
```

### 1. Task Decomposition

A large task is divided into discrete, manageable sub-tasks. For example, instead of asking the AI to "read this document, summarize it, translate it, and draft a reply," each action is separated.

### 2. Intermediate Processing

The first prompt processes the raw input data (e.g., extracting bullet points from a long article). The response generated by the AI becomes part of the text string given to the next prompt in the pipeline.

### 3. Progressive Refinement

Subsequent prompts use the output of previous steps to build deeper analysis, verify accuracy, or format the result into specific structures (like JSON, code, or polished email text).

## Example: Building a Product Review Summarizer

Here is how prompt chaining looks in practice for analyzing customer feedback:

|**Step**|**Goal**|**Input**|**Prompt Action**|
|---|---|---|---|
|**Step 1**|**Extraction**|Raw customer review text|"Extract all pros and cons mentioned in this text as two bullet lists."|
|**Step 2**|**Sentiment Analysis**|Output from Step 1|"Based on these pros and cons, score the customer sentiment from 1 to 10 and list key feature requests."|
|**Step 3**|**Response Draft**|Output from Step 2|"Draft a 3-sentence polite response from customer support addressing the key feature requests identified."|

## Why Use Prompt Chaining?

- **Higher Accuracy:** Breaks down complex logic so the model isn't overwhelmed by competing instructions in a single context window.
    
- **Reduces Hallucinations:** Constraining each step to process verifiable intermediate outputs keeps the AI focused on real data.
    
- **Easier Debugging:** If the final answer is incorrect, you can inspect each intermediate step to see exactly where the reasoning failed.
    
- **Modular Workflows:** Individual prompts in the chain can be updated or swapped without rebuilding the entire system.
